====================================================================
HISABPRO DESKTOP (v1.3.0) — WINDOWS 10 & WINDOWS 11 (64-BIT)
====================================================================

Thank you for installing HisabPro Desktop for Windows.

SYSTEM REQUIREMENTS
- Windows 10 (64-bit) or Windows 11 (64-bit)
- Minimum 4 GB RAM, 350 MB free disk space
- No separate Java, Node.js, or database software required (all
  required runtime components are bundled inside HisabPro_Setup.exe)

QUICK INSTALLATION
1. Extract HisabPro_Windows_Complete.zip to any folder on your PC.
2. Double-click HisabPro_Setup.exe.
3. Accept the Windows administrator prompt if shown and follow the
   on-screen installer steps.
4. Click Finish — HisabPro launches automatically and adds both a
   Desktop shortcut and a Start Menu shortcut.

FEATURES INCLUDED
- Unified Cloud Sync with HisabPro Android (same company, shops,
  bookers, products, bookings, credit, recovery, and ledger reports)
- Offline SQLite WAL Database with automatic sync and conflict
  protection (zero duplicate entries)
- 6-column A4 Supplier Ledger PDF export & Windows native printing
- Excel (.xlsx), CSV, and JSON/SQLite backup & restore
- Role-based security for Company Admin, Authorized Staff, Booker,
  and verified Platform Owner

LOCAL DATA & UNINSTALL SAFETY
- Offline transactions and encrypted session settings are stored in:
  %LOCALAPPDATA%\HisabPro
- Uninstalling HisabPro removes program files only and preserves
  your cloud records and local offline database safely.
